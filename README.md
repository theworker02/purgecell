# purgecell

Purge URLs and cell query parts with stable normalization.

**Site:** https://theworker02.github.io/purgecell/

## Install / run

```bash
git clone https://github.com/theworker02/purgecell.git
cd purgecell
node src/cli.js
node --test
```
